# Car 04 Race Restomod

Compiled TLDLoader mod DLL: `M_Car04RaceRestomod.dll`.

This mod targets the game's `gcar04` database prefab, applies its blue-and-orange race livery, and shows live speed, gear, RPM, fuel, and oil telemetry while you're driving it.

Copy the DLL into the game's TLDLoader mods directory to install it. Source and build notes are in `src/Car04RaceRestomod/`.
